### Which platforms are supported?

3psLCCA installers are available for Windows and Linux, with a Conda package covering all
platforms including macOS. See [Getting Started](./getting-started.md) for installation
instructions and current system requirements.

---

### Where can I report a bug or request a feature?

Open an issue on [GitHub Issues](https://github.com/3psLCCA/3psLCCA-gui/issues). Include your
platform, 3psLCCA version, and steps to reproduce the problem.

---

### Can I build my own version of 3psLCCA?

Yes. Clone the [3psLCCA-gui](https://github.com/3psLCCA/3psLCCA-gui/) repository and follow the
build instructions in its README to set up and run the application from source.
